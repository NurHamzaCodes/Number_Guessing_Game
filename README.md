## Number Guessing Game

A simple Python project where the computer tries to guess the number the user has in mind.

The user thinks of a number between **1 and 100**, and the program asks whether its guess is **less than, equal to, or greater than** the user's number.

## How It Works

The program uses **Binary Search** to narrow down the possible number.

* `-1` → The user's number is smaller than the guess.
* `0` → The guess is correct.
* `1` → The user's number is larger than the guess.

This allows the program to find the number in a small number of questions.
